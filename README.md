# Лабораторна робота 11 — Варіант 6

Основи функціонального програмування в C++23. Окремо реалізовано усі обов'язкові частини 1–5 і додаткову частину 6 у десяти самостійних програмах.

## Запуск у Visual Studio

Відкрийте папку `Lab11_Variant6` у Visual Studio 2022 або новішій через **File → Open → Folder**. Visual Studio автоматично прочитає `CMakeLists.txt`. Оберіть конфігурацію x64 та одну із десяти цілей (`Part1_Lambda` ... `Part6_Sensors`) і запустіть її. У кожному файлі власний `main()` — усі файли не можна компілювати як один виконуваний модуль.

Альтернативно з термінала:

```bash
cmake -S . -B build
cmake --build build --config Release
```
